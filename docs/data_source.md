# Data source and provenance

Source: [Kenneth R. French Data Library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)
Dataset: **5 Industry Portfolios [Daily]**, value-weighted returns
Direct download: <https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/5_Industry_Portfolios_Daily_CSV.zip>

The source file contains daily percentage returns for five industry portfolios
constructed from eligible NYSE, AMEX, and NASDAQ firms. The provider notes that
the portfolios are reconstructed as the underlying CRSP database is updated,
so historical values may change. For that reason, the download script records
the retrieval time, archive SHA-256 digest, date range, and row count.

Raw source files are ignored by Git and are not redistributed in this
repository. Only aggregate model-validation tables, charts, and summaries are
committed. Users should review and comply with the provider's current terms.
